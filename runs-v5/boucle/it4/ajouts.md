- C14 : Quand une page qualifie une pièce de facultative ou d'obligatoire par une mention jointe à son intitulé, après le lancement de l'analyse, le nom de la pièce est son intitulé sans cette mention et son obligation pièce porte cette qualification, avec pour page valeur la page qui la qualifie | observé: pièces | conditions: texte pages | cas: 1
- C15 : Quand une page indique le mode de remise des offres et qu'une page, la même ou une autre, mentionne aussi le support sur lequel le marché attribué sera signé, après le lancement de l'analyse, le mode remise affiche seulement le mode de remise des offres, avec pour page valeur seulement la page qui l'indique, et aucun conflit valeurs n'est signalé pour le mode remise | observé: mode remise | conditions: texte pages | cas: 3
- écarté : 2 | raison: le comportement retenu (lot unique sans numéro + deux lots numérotés, soit trois lots) contredit A45 (« Quand une page déclare que le marché n'est pas alloti, le dossier liste exactement un lot ») et A01 (« Quand le texte des pages décrit deux lots, le dossier liste exactement ces deux lots ») sur la même entrée ; la décision est de plus provisoire, la question étant posée au client — l'arbitre doit d'abord retirer ou amender A45/A01.
