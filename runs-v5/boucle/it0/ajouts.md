- C01 : Quand une même page exprime les pondérations des critères en pourcentages et celles de leurs sous-critères en points, après le lancement de l'analyse, le type pondération est trouvé avec une seule valeur et aucun conflit valeurs n'est signalé pour le type pondération | observé: conflit valeurs | conditions: texte pages, type pondération | cas: 1
- C02 : Quand le type pondération vaut « pourcentage » et que la somme des critères diffère de 100 %, après le lancement de l'analyse, l'alerte « total différent de 100 % » est affichée une seule fois et porte sur l'objet « critères » | observé: objet alerte | conditions: pondération, type pondération | cas: 2
- C03 : Quand une seule page fixe la durée de validité des offres, une seule fois, après le lancement de l'analyse, la validité offres est trouvée avec cette seule valeur et aucun conflit valeurs n'est signalé pour la validité offres | observé: conflit valeurs | conditions: texte pages | cas: 4
- C04 : Quand une page nomme le mode de remise des offres et qu'une autre page se borne à exclure un autre mode sans nommer le mode retenu, après le lancement de l'analyse, le mode remise affiche seulement le mode nommé, avec pour page valeur seulement la page qui le nomme | observé: page valeur | conditions: texte pages | cas: 5
- écarté : 3 | raison: le comportement retenu ([2 mois p.1, 90 jours p.1]) contredit l'assertion proposée et A12 — un RC avec une seule durée de validité ne peut pas rendre deux valeurs sur la même page ; « 2 mois » est le délai de recours type, donc le comportement retenu contient justement le délai qui « ne porte pas sur la validité des offres », et l'interface imposerait alors conflit True sur un RC sans contradiction. Aucune assertion à la fois fidèle à ce comportement et compatible avec A12/A14 n'est possible ; le cas doit revenir à l'arbitre (le texte de la page n'a pas été fourni pour savoir quelle valeur est la validité).
