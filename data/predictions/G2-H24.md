# Prédiction figée : G2, H24 (λ2 de Fiedler contre k)

Écrite le 20/11/2026, **avant tout calcul de λ2** sur une passe. Le commit qui ajoute ce fichier fait foi.

## Ce qu'on calcule (choix fixés avant)

- Graphe : celui de `outils/mesure.py` (une assertion = un nœud ; arête si deux assertions partagent un état hors champ ; poids = nombre d'états partagés).
- λ2 : deuxième plus petite valeur propre du **laplacien normalisé** pondéré, sur la **plus grande composante connexe** (un graphe non connexe a λ2 = 0, ce qui ne dirait rien). Normalisé pour ne pas mesurer la taille.
- On note aussi la part des assertions hors de la plus grande composante.
- Passes : toutes les passes v2 (`data/passes/strict-v2`, P01 à P10) et v2-xl (P11). Jamais mélangées avec v1.

## Prédictions

1. **Reproductibilité (comme H13).** Écart relatif entre passes d'une même sonde, |a − b| / moyenne (à 3 passes : (max − min) / médiane). Prédiction : l'écart relatif médian de λ2 est **au moins 3 fois** celui de k sur les mêmes sondes. λ2 dépend de quelques arêtes faibles ; k est une moyenne.
2. **Tours.** Sur les 7 sondes qui ont eu un duel à partir de passes v2 (P02, P05, P06, P07, P08, P10, P11 ; tours : 2, 2, 3, 2, 3, 4, 4), ρ de Spearman entre la valeur retenue (médiane des passes) et les tours. H24 est **confirmée** si |ρ(λ2, tours)| ≥ |ρ(k, tours)| + 0,20, avec un signe qui a un sens (λ2 haut = décision qui se propage vite = plus de tours). Prédiction : **réfutée**, l'écart sera sous 0,20.
3. **Trous.** Les trous mesurés à l'exécution n'existent que pour P02 et P11 (test différentiel) : 2 points, pas de corrélation possible. Cette moitié de H24 **n'est pas testable** sur les données existantes ; elle se testera sur la tranche V5 (chaque section de la spec aura ses trous).

Limite connue avant calcul : 7 points. À n = 7, il faut |ρ| ≥ 0,79 pour un seuil de 5 %. Un écart de 0,20 entre deux ρ non significatifs reste une indication, pas une preuve.
