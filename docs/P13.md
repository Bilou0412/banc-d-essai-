## Suite : le test différentiel à 4 greens (26/11, à la demande de Bilel)

Sur la spec **d'avant l'audit** (les mêmes 40 assertions de la passe A et les 96 tests du duel), sans rien corriger. `outils/differentiel.py` : générateur écrit par un red opus (0,31 $), 4 greens neufs (H1, H2 haiku ; S1, S2 sonnet), tous à 96/96 au premier tour (0,41 $), 300 situations par paire, juge opus sur chaque groupe de divergences (0,39 $). Données : `runs-v4/P13/`.

| Paire | Taux de compilation | Groupes jugés |
|---|---|---|
| H1-H2 | 0,143 | 2 trous |
| H1-S1 | 0,140 | 1 trou |
| H1-S2 | 0,140 | 1 trou |
| H2-S1 | 0,310 | 2 trous |
| H2-S2 | 0,310 | 2 trous |
| S1-S2 | 1,000 | aucun |
| **Lot de 4** (`quatre.py`) | **0,12** (36 / 300 identiques chez les 4) | |

Premier écart dans le lot de 4 : « 3 contre 1 » 220 fois (H1 seul sur la prévision 142, H2 seul sur la commande 78), « 2 contre 2 » 44 fois. Les deux sonnet sont identiques (corrélés, comme en V5).

Les **2 trous distincts** derrière les 8 groupes :

1. **Le commentaire du mentor après une prévision juste** : montre-t-il la moyenne mobile et les 3 nombres ? (806 divergences ; validation). L'audit l'avait relevé (V7).
2. **La demande tirée depuis la graine** : la spec ne fixe ni le générateur ni l'ordre des tirages (381 divergences ; données). L'audit l'avait relevé (D3, D4).

Aucun bug, aucune contradiction. Aucun trou économique : les 4 greens ont fait les mêmes ventes, ruptures, jeté, recette, coût et bénéfice. Le trou « demande ou ventes dans l'historique » (C1), que les deux passes aveugles avaient lu différemment, n'a pas divergé : les 4 greens ont ajouté la demande.

### Verdict H32 : confirmée pour le sens, pas pour la parenthèse

| Seuil figé (pour le duel) | Test différentiel |
|---|---|
| ≥ 5 échecs | 8 groupes jugés : tenu |
| ≥ 60 % de trous | 100 % : tenu |
| ≤ 10 % de contradictions | 0 % : tenu |
| trous ≥ bugs | 8 contre 0 : tenu |
| ≥ 60 % des trous en validation ou économie | 1 trou distinct sur 2 (50 %) ; 68 % des divergences ; 0 trou économique : **non tenu** sur les trous distincts |

Les seuils étaient écrits pour le duel ; les appliquer au test différentiel est un choix fait après le duel : **non validé** (règle 6). Ce que ça dit : une spec de simulation à formules objectives ne produit ici ni bug ni contradiction, seulement des trous, mais ses formules économiques compilent du premier coup ; les trous sont dans ce que la spec ne fixe pas autour des formules (le hasard reproductible, ce que dit le mentor).
